# xfb-analytics-hackathon-2025

Welcome to my xfb-analytics-hackathon-2025 repository!

This repository showcases my submission for the **Football Analytics Hackathon 2025**, an event organized by **xfb Analytics** in partnership with **Transfermarkt**. It was a great opportunity to dive deep into football data and explore ways in which data-driven strategies can enhance the sporting performance of professional clubs.

---

## 📌 Project Overview

The aim of this project was to:

- **Select one English Premier League club** as a case study.
- **Identify two key areas** for sporting improvement within the team, using performance data and contextual insights.
- For each area, **propose a list of five targeted player transfers**, focusing on athletes whose attributes, style of play, and potential fit align with the club's tactical identity and values.
- **Provide a detailed analysis** of each top transfer target, including supporting data and reasoning.

More information can be found in the attached document:  
📄 `Hackathon_Task_Description_2025.pdf`

---

## 🏆 Results

I'm proud to share that my report was selected as a **finalist**!  
As part of the recognition, I was invited to **present my analysis at the Football Forum Hungary 2025**, held at the **Groupama Arena in Budapest** in April 2025.
